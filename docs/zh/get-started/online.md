# 在线完成第一次检索

在 [paperseek.app](https://paperseek.app/) 上把一个问题变成阅读清单，无需安装。大约五分钟。

更想用自己的设备？[安装社区版](local.md)。

## 开始之前

- 一个用于注册账户的邮箱。公测期间每个账户每天获得 **20 免费积分**，一次检索消耗 **1 积分**。详见[服务与积分](../online/credits.md)。
- 没有账户？可以不登录做一次临时检索，见[不登录检索](../online/privacy.md#不登录检索)。临时检索不会保存。

## 1. 登录

打开 [paperseek.app](https://paperseek.app/)，点击侧栏底部的 **未登录**，选择 **登录或注册**。输入邮箱，确认验证码，设置密码。详细信息和其他登录方式见[账户与登录](../online/account.md)。

## 2. 输入问题

登录后默认使用 **PaperSeek 服务**：模型由 PaperSeek 提供，任务消耗每日积分。

打开侧栏的**文献检索**。保留默认数据源 **OpenAlex**，预算保持 **Auto**，输入你的问题，例如：

> 开源软件如何获得支持长期维护的资金？

点击**开始检索**，或按 **Ctrl+Enter / ⌘+Enter**。表单会显示本次任务消耗的积分和今日剩余积分。

## 3. 查看检索进展

PaperSeek 分四个可见阶段工作：理解问题、迭代适合数据源的检索式、召回并排序候选，最后呈现结果。运行中可以随时在页首停止。各阶段和数量的含义见[检索文献](../guide/search.md)。

## 4. 阅读结果

运行结束后打开**检索结果**。每篇文献显示摘要、带文字理由的相关性评分和原始记录链接。可将清单导出为 CSV、JSON、BibTeX 或 RIS。

这次运行会保存到你的账户，可从侧栏的**检索历史**重新打开。从这里还可以打开[引用图谱](../guide/citation-map.md)、运行[文献计量分析](../guide/bibliometrics.md)，或开始一篇[实验性综述](../guide/reviews.md)。
