# 使用指南

两种使用方式通用的 PaperSeek 工作区任务指南。初次使用？从[快速上手](../get-started/index.md)开始。

## 研究流程

- [检索文献](search.md) — 问题、数据源、预算和一次运行的四个阶段。
- [结果与历史](results.md) — 阅读、筛选、选择和导出文献；重新打开历史运行。
- [引用图谱](citation-map.md) — 探索初始结果之外的引用联系。
- [文献计量](bibliometrics.md) — 分析召回的候选集：趋势、发表载体、作者和网络。
- [文献综述（实验性）](reviews.md) — 基于选中的摘要证据撰写文献综述草稿。
