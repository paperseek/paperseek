# 文献计量

在顶部的**文献计量**中，分析一次已保存检索的元数据。每份分析拥有独立标题、历史和导出。

## 创建分析

选择已完成的检索，或从检索结果进入计量分析。系统保存精简候选元数据的独立快照，删除来源检索不会删除分析。

分析范围是**实际获取并去重的候选集**，包含已获取的引用扩展候选；不是数据源报告的命中总数、整个研究领域，也不只是最终相关性排序结果。检索仍受预算限制，LLM 仍只评分原来的子集。创建分析不会给全部候选打分，不调用语言模型，也不会自动补抓缺失元数据。

旧检索若没有候选集文件，只能使用其已保存的最终结果，界面会明确标记这一降级范围。如需较完整的候选集，需要重新检索。

## 子功能

| 页面 | 内容 |
| --- | --- |
| 概览 | 年份、来源期刊/会议、文献类型、作者、机构、国家/地区、被引数据覆盖及评分子集 |
| 期刊分区 | 中科院分区与 Top、JCR 分区、CCF 类别的分布，以及带影响因子的期刊与会议分级表 |
| 关键词 | 原生关键词或来源分类、词频，以及按需生成的共现网络 |
| 文献关系 | 文献耦合：用共同的已返回参考文献连接论文 |
| 数据质量 | 字段覆盖率、缺失值、分析范围及来源限制 |

期刊分区在创建分析时，用本机已下载的 [ShowJCR 分区数据](results.md#期刊分区与会议录用)为整个分析语料打标签，不限于已评分的文献。分区数据下载之前创建的分析没有分区标签，对同一检索重新创建即可。只有 JCR 的 IF 是影响因子。

缺失被引数保留为未知，明确返回的零才计为零。作者和机构仅按返回名称整理，未做实体消歧。国家/地区来自机构信息，不表示作者国籍。关键词会标明来源；OpenAlex 概念、Semantic Scholar 学科分类不能直接等同于作者关键词。

## 生成网络

打开网络子页不会自动计算。调整阈值后点击**生成网络**；参数区在提交后收起，可在画布上方重新展开。通过节点搜索、节点详情和分组图例探索网络。服务端按参数缓存已完成结果，图形布局由浏览器 worker 处理；布局失败时可重试。

共现表示词语在同一篇文献中出现；文献耦合表示论文拥有共同参考文献。分组使用连通分量，不代表经过验证的语义主题。两种关系都不能证明论文支持某个写作结论；这类核对请使用综述中的**引用证据**。

单图最多显示 **300 个节点、2,000 条边**。稀疏计算还限制候选配对工作量；过密语料需要提高阈值或排除极高频参考文献。界面会提示显示截断和省略情况。分类统计最多保留 100 类，导出保留底层精简候选集。

## 历史与导出

在左侧栏选择**文献计量**后，**分析记录**区域显示该模块的记录。点击记录重新打开，点击标题旁的放大镜搜索，或点击**全部**打开完整列表。列表中每行的记录菜单提供重命名、导出和删除。重命名只改显示标题，不改来源检索问题。

CSV 按文献逐行导出，JSON 同时提供候选集与范围信息；两者与只包含最终结果的检索导出不同。删除分析会清理其快照和网络缓存，保留来源检索及综述。

## 解读边界

这是针对单次有限检索的初步文献计量。数据源覆盖、参考文献缺失、名称变体和检索式选择会影响分布与网络，不能替代可复现的多数据库系统检索或专门的计量验证。
