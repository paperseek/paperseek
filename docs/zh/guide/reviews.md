# 文献综述

**实验性功能。** 将选定文献的摘要证据组织成主题大纲，生成可编辑且带引用的草稿。

该功能使用已有论文与摘要，不会自动读取完整 PDF。请对照原始研究核查草稿。

## 模块与证据

综述包含文献、大纲、正文和引用证据四个子页。当前综述的模型配置在综述页的模型折叠区中调整，生成期间不能修改。历史侧栏只显示综述；引用证据集中提供段落引文与文献关系图。新综述独立保存可用的来源图快照，旧综述仍可能依赖来源检索。

## 1. 选择检索

从结果勾选后进入，或打开**综述 → 新建综述**，选择已有检索。

在线综述需要登录和已保存的来源检索；社区版保存在本地。

## 2. 设置范围

填写主题，选择中文或英文、写作模型，以及简短、标准或详细。

默认章节数分别为 **1、3、6**，可自定义 **1–14 章**。这不保证固定字数，证据与大纲决定了适合写作的内容。

社区版和在线版自带密钥模式可以配置写作模型，PaperSeek 服务从允许的模型中选择。

## 3. 选择文献

篇幅决定建议选用的文献数量：简短约 **8–20 篇**，标准约 **20–45 篇**，详细约 **40–80 篇**；自定义章节或段落时按段落数估算。上限为 **100 篇**。

可以手动勾选，也可以点击**按主题自动挑选**：写作模型从这次检索的全部结果中挑出覆盖不同主题、方法和研究对象的文献，并给出每篇的挑选理由。挑选结果仍可增删。自动挑选不计入写作次数，使用 PaperSeek 服务时也不扣积分。

只能选择有摘要的文献。文献更多不代表证据更好，缺乏有效研究内容的记录可能不会参与正文。

## 4. 检查大纲

审阅主题、章节结构、段落计划和文献分配，检查遗漏视角及超出证据的写作范围。

每个段落计划最多分配 **10 篇**文献。大纲用不上的文献会列在**未纳入大纲的文献**中，并附上不纳入的理由。要重新纳入，在某一章的支撑文献里添加即可；从所有章节移除的文献会自动记为手动移除。

点击**保存大纲**只保存修改，不启动写作；准备好生成正文后，再点击**确认大纲并执行**或**保存大纲并执行**。离开未保存的编辑时，会提示继续编辑或放弃修改。

## 5. 阅读与修订

可以编辑文字、单节重写并查看可用版本。修改大纲不会自动让旧正文与新大纲一致，应检查当前版本和任务状态。

引文可选择顺序编号或 Harvard 作者—年份，导出沿用所选呈现方式。

写作时，模型可以不引用某篇计划文献，但要说明理由，例如与本段比较的问题无关或与另一项研究重复。每章末尾的**未引用的计划文献**列出这些文献和理由；证据核对认为理由可能不成立时会标出，并说明依据。

段落中引用了、但没能对应到具体论断的文献，会单独列在该段下方的**未对应到具体论断的引用**中，导出时同样保留。

证据检查能提示支撑不足或不一致，但不能证明科学结论正确。依赖论断前仍需阅读原始论文。

## 6. 导出

- **Markdown**：继续编辑。
- **Word（.docx）**：文档写作。
- **BibTeX**：管理参考文献。

## 生成中断时

当前或最近任务的状态与已保存正文分开展示，停止任务不会抹除大纲或已经完成的章节。模型访问、余额、超时和结构化响应错误可能导致大纲或正文中断。修正原因后重试受影响操作，不必创建重复综述。

刷新连接已保存状态，不会重启生成。在线写作与检索共用[执行队列](../online/index.md#任务排队)。
