# 结果与历史

阅读检索清单，选择重要文献，再导入自己的研究流程。

## 三类独立历史

检索运行、分析和综述分别保存，侧栏中的每个模块只显示自己的历史。历史保存在哪里、记录如何重命名、导出或删除，以及刷新后什么会保留，见[工作区与历史](workspace.md)。

## 阅读文献卡片

结果可能包含标题、作者、年份、发表载体、摘要、原始链接、标识符、引用信息和相关性理由，具体取决于数据源。

相关性衡量与**你的问题**的匹配程度，不是研究质量评分，也不能代替阅读原文。

## 筛选、排序和选择

结果控件针对本次返回的集合进行搜索、筛选与排序，不会重新向外部数据源检索。

勾选文献可导出子集或整理综述，继续前应确认已选数量。**选择已加载**只勾选当前已加载的文献，创建综述需选择 2–256 篇。切换模块会保留本次会话中的勾选。

## 导出

| 格式 | 用途 |
| --- | --- |
| CSV | 表格整理与人工筛选 |
| JSON | 后续程序处理 |
| 已选 CSV / JSON | 仅包含勾选文献 |

**导出**菜单集中提供全部结果和已选文献的 CSV / JSON 下载。完整导出覆盖已保存结果，不仅是当前分页。原始记录链接指向数据源，PaperSeek 不会批量下载付费全文。

[综述导出](reviews.md)使用 Markdown、Word 与 BibTeX。

## 重新打开历史

社区版历史属于本地数据库，在线历史属于已登录账户。[匿名检索后再登录](../online/privacy.md#不登录检索)不会自动补存。

历史保留当时的实际设置，不会被今天的默认模型或预算覆盖；旧版未记录的字段保持未知。

可删除已结束的记录，删除前请导出需要保留的内容，活动任务必须先结束。

## 创建综述

选择至少两篇具有有效摘要的文献，或从 **文献综述** 新建。后续步骤见[大纲与写作指南](reviews.md)。
