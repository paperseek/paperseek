# 检索文献

描述你希望理解的问题，PaperSeek 会生成适合数据源的检索式，并展示检索如何逐步展开。

## 工作区入口

检索设置、运行过程、检索结果是模块内的三个子页。模型默认值位于侧栏底部的独立设置页；来源、领域与检索预算留在检索草稿中。运行时可在页首停止任务，切换子页不会重跑任务。

## 写清研究问题

说明研究对象和关注的关系，必要时加入方法、群体、时期或场景。

**宽泛：**“开源软件。”  
**具体：**“不同资金支持机制如何影响开源软件的长期维护？”

支持中英文自然语言，不必手写布尔检索式。问题最多 10,000 个字符。

## 选择数据源和范围

一次任务从**一个选定数据源**开始。多路召回不代表同一任务会同时查询八个来源。

OpenAlex、arXiv 和 WoS 有源特定的领域筛选；其他来源使用领域提示辅助规划检索式。文本提示不等于数据库层面的强制过滤。

OpenAlex 引用扩展在预算内增加参考文献和施引文献，也会增加请求和耗时。

## 选择预算

| 界面选项 | API / CLI 值 | 用途 |
| --- | --- | --- |
| Auto | — | 由 PaperSeek 选择检索预算 |
| 快速 | `fast` | 较小召回与评分预算 |
| 均衡 | `medium` | 扩大覆盖与排序深度 |
| 深入 | `high` | 更多候选与引用探索 |
| 最大 | `max` | 最大的有界检索预算 |

预算限制工作量，不保证固定文献数或完成时间。更大预算可能更慢、更贵，收窄问题可能比选择最大档更有帮助。

## 理解四个阶段

1. **检索意图与检索式**：理解范围，制定策略。
2. **检索迭代**：根据数据源反馈测试与调整查询。
3. **候选召回与排序**：收集候选、按需扩展引用、初排序，再评估相关性。模型先按每批 64 篇给候选打分，再按每组 32 篇为得分较高的论文写“排序理由”；最多同时进行 8 批或 8 组，打分和写理由各有一行进度。
4. **文献结果**：整理阅读清单与导出。

页面展示阶段状态和详情，不再显示原始终端日志框。

### 区分几种数量

数据源报告数万条命中时，程序可能只下载了一页。**数据源命中**、**已召回候选**和**最终结果**不是同一个集合。

过宽的查询可能先收窄再获取候选池。重复或无进展的改写会停止，并可回选历史中更合适的查询，而非无条件采用最后一轮。候选池始终受预算限制，输出不代表穷尽相关文献。

## 停止与重连

点击**停止**请求取消，正在进行的工作收尾时可能短暂显示**正在取消**。

刷新持久化任务会恢复已保存的状态，网络重连不是新检索。重试已结束或取消的任务会开始新的执行，不会重开旧执行。

在线排队见[在线版概览](../online/index.md#任务排队)，匿名会话见[数据与隐私](../online/privacy.md#不登录检索)。
