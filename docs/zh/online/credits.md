# 服务与积分

PaperSeek 服务是在线版的默认模式：模型由 PaperSeek 提供，任务消耗每日积分，不使用你自己的服务商账户。

## 使用 PaperSeek 服务

1. 登录。默认即为 PaperSeek 服务。
2. 填写研究问题，选择数据源和检索预算。
3. 开始检索。表单会显示本次任务消耗的积分和今日剩余积分。

检索和综述都使用 **Default**，即 PaperSeek 选定的内置模型。初排序在 **设置 › 模型服务** 中配置。可用数据源以应用中显示的为准。站点不提供 Web of Science 和万方数据的密钥，在**设置 › 模型服务**中保存自己的密钥后，使用 PaperSeek 服务也能检索这两个库。

## 积分

公测期间，每个账户每天获得 **20 免费积分**。只有 PaperSeek 服务消耗积分：

| 任务 | 积分 |
| --- | --- |
| 文献检索 | 1 |
| 文献计量 | 1 |
| 文献综述 | 一整篇 5 |

积分在提交任务时扣除。一篇综述只扣一次，由它的第一个写作任务扣除；同一篇综述之后重新生成大纲、写作正文、重写章节都不再扣。挑选文献时的**按主题自动挑选**免费，也不计入写作次数。任务失败或被取消会退回积分；带警告完成的任务不退回。

剩余积分显示在侧栏和 **设置 › 用户** 中，并注明每日恢复时间。

## 申请更多积分

公测期间如需更大用量，请发邮件至 [support@paperseek.app](mailto:support@paperseek.app)，正文写明账户 ID（在 **设置 › 用户** 中复制）、所在单位和你使用 PaperSeek 的方式。
