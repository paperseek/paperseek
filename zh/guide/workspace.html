工作区与历史 ​

介绍 PaperSeek 工作区的结构、数据保存的位置，以及刷新后保留的内容。结果层面的操作见结果与历史。

通过左侧栏进入文献检索、文献计量、文献综述，从各模块的历史记录重新打开已保存的检索、分析或综述。

模块子功能历史记录对应对象
文献检索检索设置、运行过程、检索结果一次检索任务
文献计量概览、关键词、文献关系、数据质量一份独立候选集分析
文献综述文献、大纲、正文、引用证据一份可编辑综述

左侧历史栏只显示当前模块的记录。顶部按钮可隐藏或显示整个侧栏，小屏幕则使用可关闭的抽屉。通过新建按钮创建草稿，点击历史标题旁的放大镜搜索记录，点击全部打开当前模块的完整历史列表。尚未保存或提交的新草稿不会成为历史记录。

完整历史列表中的记录菜单提供重命名、导出和删除。重命名不改检索问题、综述主题或原始运行参数。删除需要确认，正在运行的任务不能直接删除。

侧栏底部提供设置、文档帮助和账户菜单。设置包含模型 API、数据源、通用、用户四页，对应 /settings/models、/settings/sources、/settings/general、/settings/user。通过侧栏模块入口或浏览器后退返回工作区。

新增或编辑模型连接后，需要在弹窗中点击保存。数据源配置弹窗中的保存会持久保存密钥和选项；测试连接也会先保存，再测试。测试失败或随后取消弹窗，都不会撤销这次保存。默认模型和初排序选项在选择时自动保存，作用于新草稿；历史检索保留原执行配置。综述中的模型设置作用于当前综述，生成期间不能修改。用户页展示本地数据位置，并提供已保存密钥和历史数据管理。语言可在通用设置、顶部栏或账户菜单切换；在线版账户菜单还提供账户和服务相关操作。

临时输入、已保存密钥与浏览器状态 ​

  • 尚未保存的表单输入和草稿只存在于浏览器内存，刷新后丢失。模型连接弹窗中的测试连接会发送草稿给服务端，但不保存；数据源配置弹窗中的同名操作会先保存，此后即使测试失败，输入也已成为保存的配置。数据源列表中的测试和全部测试使用已配置的凭据。
  • 已保存的模型连接和数据源密钥持久保存在服务端。社区版使用数据库旁的 credentials.master.key 加密数据库中的密钥值，刷新页面或重启服务不会清除。设置接口仅返回密钥状态和脱敏末尾，不回传已保存的明文密钥。
  • 已提交任务可能另存一份加密凭据，用于执行和恢复。设置 → 用户 → 清空已保存的密钥会删除保存的连接和数据源密钥，但不影响已经提交的任务。
  • 浏览器存储保存语言、侧栏显隐等偏好，不保存 API 密钥。清理浏览器存储或刷新页面不会删除服务端密钥。

引用图谱放在综述的引用证据 → 文献关系中。旧图谱与历史直达链接继续可用。

切换模块保留本次浏览器会话中的已加载结果、筛选、勾选和滚动位置。结果缓存保留最近访问的十次检索，刷新后清空这些临时状态。离开未保存的大纲或段落编辑时，会提示继续编辑或放弃修改；刷新前请先保存。

新综述会将可用的来源引用图保存在自身证据中，删除来源检索后仍可查看；没有这份快照的旧综述仍依赖来源记录。文献计量分析始终保存自己的候选集快照。
