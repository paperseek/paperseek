结果与历史 ​

阅读检索清单，选择重要文献，再导入自己的研究流程。

三类独立历史 ​

检索运行、分析和综述分别保存，侧栏中的每个模块只显示自己的历史。历史保存在哪里、记录如何重命名、导出或删除，以及刷新后什么会保留，见工作区与历史。

阅读文献卡片 ​

结果可能包含标题、作者、年份、发表载体、摘要、原始链接、标识符、引用信息和相关性理由，具体取决于数据源。

相关性衡量与你的问题的匹配程度，不是研究质量评分，也不能代替阅读原文。

期刊分区与会议录用 ​

卡片上可能有两类发表载体标签，打开详细书目信息可查看完整内容。

  • 期刊与会议分级：中科院分区与 Top、JCR 分区与影响因子，以及 CCF 推荐会议和期刊的 A、B、C 类，均来自 ShowJCR。中科院与 JCR 先按 ISSN 匹配，没有 ISSN 时按期刊全名精确匹配，按刊名匹配的会在详情中注明；CCF 按会议或期刊全名、或 NeurIPS 这样的缩写匹配，workshop 不标 CCF 类别。只有 JCR 的数值是影响因子，中科院分区、JCR 分区和 CCF 类别都是分级。
  • 中文核心期刊：北大核心，以及分开标注的三类 CSSCI：来源期刊、来源集刊和扩展版，详情中会注明版本。这份目录由 PaperSeek 整理，没有 ISSN，所以按中文刊名或曾用名匹配，括号、全角半角标点和“（中英文）”不影响匹配。几种期刊共用的名称不标注，例如不带版别的“北京大学学报”。
  • 开放影响力：OpenAlex 提供的期刊 2 年篇均被引和 h 指数，无需导入，不是影响因子。
  • 会议录用：会议、年份以及 Oral、Spotlight 或 Poster，来自 PaperHub 收录与 OpenReview。只计入会议主会场、NeurIPS Datasets & Benchmarks 和 TMLR 录用的论文，workshop、被拒、撤稿和审稿中的投稿不算。

标签在检索结束时写入。ShowJCR 的数据在首次检索时从 GitHub 下载并保存在本机，设置 → 数据源 → 期刊分区数据显示当前版本，点全部更新可重新下载，北大核心与 CSSCI 目录会一并下载，两者都使用网络代理设置。无法访问 GitHub 时，可从 ShowJCR 下载同名文件（FQBJCR2025-UTF8.csv、JCR2025-UTF8.csv、CCF2026-UTF8.csv），再用导入本地文件替换。北大核心与 CSSCI 目录可导入 .xlsx 或 CSV，列依次为刊名、收录、曾用名。重新运行检索即可按新版本标注。

筛选、排序和选择 ​

结果控件针对本次返回的集合进行搜索、筛选与排序，不会重新向外部数据源检索。

期刊筛选按中科院分区、中科院 Top、JCR 分区范围、CCF 类别（A、A–B、A–C）、北大核心、CSSCI 来源期刊、来源集刊或扩展版保留文献；录用筛选保留有会议录用、仅 Oral 或 Oral 与 Spotlight 的文献；按影响因子排序先看 JCR 影响因子，再看 OpenAlex 开放影响力。没有对应标签的文献会被这些筛选排除，不做推测。

勾选文献可导出子集或整理综述，继续前应确认已选数量。选择已加载只勾选当前已加载的文献，创建综述需选择 2–256 篇。切换模块会保留本次会话中的勾选。

导出 ​

格式用途
CSV表格整理与人工筛选
JSON后续程序处理，含期刊分区与录用标签
BibTeXZotero、JabRef、LaTeX
RISZotero、EndNote、Mendeley
已选（任一格式）仅包含勾选文献

导出菜单集中提供全部结果和已选文献的下载。BibTeX 与 RIS 会把期刊论文、会议论文和预印本分别写成对应条目类型，数据源提供时带上卷、期、页码和 ISSN，并把会议录用（如“ICLR 2025 Oral”）写入备注字段。期刊分区不写入这两种文件。完整导出覆盖已保存结果，不仅是当前分页。原始记录链接指向数据源，PaperSeek 不会批量下载付费全文。

综述导出使用 Markdown、Word 与 BibTeX。

重新打开历史 ​

社区版历史属于本地数据库，在线历史属于已登录账户。匿名检索后再登录不会自动补存。

历史保留当时的实际设置，不会被今天的默认模型或预算覆盖；旧版未记录的字段保持未知。

可删除已结束的记录，删除前请导出需要保留的内容，活动任务必须先结束。

创建综述 ​

选择至少两篇具有有效摘要的文献，或从 文献综述 新建。后续步骤见大纲与写作指南。
